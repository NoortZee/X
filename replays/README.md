# Записи прогонов

Здесь лежат реплеи: `<seed>/<YYYYmmdd-HHMMSS>(N).md` — по папке на скелет базы,
кадры — в `images/<…>.png`. Формат и правила: [../docs/REPLAY.md](../docs/REPLAY.md).

Каталог версионируется вместе с кодом. Кадр снимается один раз на пару
(скелет, раскладка) и переиспользуется остальными вариантами, поэтому вес
растёт примерно на один PNG на раскладку.
